## Knowledge

- [README-workshop.md](./README-workshop.md)
  The authoritative workshop guide: setup steps, script reference, troubleshooting, demo data. Primary source for all installation teaching.

  The Compose file used for the local build. Read this when explaining what services start and how they connect.

  Shared shell functions behind all `.sh` scripts — env creation, secret generation, Docker checks. Read this to explain what `start.sh` actually does step by step.

  Upstream project documentation. Use for: understanding env variables, first-user admin flow, and high-level architecture.
