# User is a workshop facilitator, not a participant

The user's goal is to run the workshop for others, not to complete it themselves. This means teaching should prioritise: reliable setup, understanding the *why* behind each step (so they can field questions), and fast triage of common participant failures — not deep exploration of Ghostfolio features.

**Implications**: Explainers should include "what to tell participants" framing. Exercises should simulate failure modes, not just the happy path.
